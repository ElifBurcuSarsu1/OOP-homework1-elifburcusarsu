## What the Program Does

1. Prints "Hello C#"
2. Prints name, department and year on three separate lines
3. Prints the current date and time using `DateTime.Now`
4. Reads a temperature in °C and converts it to °F

The conversion uses this formula:

F = C × 9 / 5 + 32
